# notia
Notia AI 시스템 및 기능 기획

AI 시스템

Notia는 Google Gemini API를 기반으로 하는 AI 학습 플랫폼으로, 사용자의 학습 데이터를 분석하여 개인 맞춤형 학습 환경을 제공한다. AI는 단순한 질의응답 기능을 넘어 필기 내용을 이해하고, 문제를 분석하며, 단계별 풀이를 제공하고, 사용자의 학습 성향을 분석하여 효율적인 공부 방법을 제안하는 역할을 수행한다. 또한 하나의 AI가 아닌 독립적인 AI 서비스 구조를 적용하여 채팅, 필기 분석, 문제 풀이, PDF 분석, 음성 인식 등의 기능을 각각 별도의 모듈로 구성함으로써 유지보수성과 확장성을 높인다.

---

AI 채팅 기능

사용자는 학습 중 궁금한 내용을 AI에게 자연어로 질문할 수 있으며, AI는 교과서 수준의 개념 설명부터 심화 내용까지 단계적으로 설명한다. 단순히 정답만 제시하는 것이 아니라 풀이 과정을 세분화하여 제공하고, 필요한 경우 그림, 표, 예시, 그래프 등을 활용하여 이해를 돕는다. 또한 사용자의 이전 질문과 학습 기록을 기억하여 연속적인 학습이 가능하도록 지원한다.

---

AI 문제 풀이

카메라 또는 갤러리를 통해 촬영한 문제를 OCR 기술로 인식한 후 문제 유형을 분석하고, 수식과 그래프를 자동으로 해석하여 단계별 풀이를 제공한다. 사용자가 원할 경우 힌트만 제공하거나 오답 원인을 분석하며, 유사 문제와 심화 문제를 자동 생성하여 반복 학습이 가능하도록 지원한다.

---

AI 필기 분석

사용자가 작성한 손글씨를 AI가 인식하여 디지털 텍스트로 변환하고, 필기 내용을 자동으로 정리한다. 핵심 개념을 추출하여 요약 노트를 생성하며, 중요한 내용을 강조 표시하고 마인드맵 형태로 재구성한다. 또한 오탈자나 잘못된 개념을 발견하면 수정 사항을 제안하고, 부족한 내용을 보완할 수 있는 학습 자료를 추천한다.

---

AI PDF 학습

PDF 교재나 학습 자료를 불러오면 AI가 문서를 분석하여 핵심 내용을 요약하고 중요 개념을 정리한다. 문서 전체를 기반으로 예상 문제와 객관식·주관식 퀴즈를 자동 생성하며, 사용자가 이해하지 못한 부분에 대한 추가 설명도 제공한다. PDF 위에 필기한 내용까지 함께 분석하여 복습 자료를 자동 생성하는 기능도 포함한다.

---

AI 실시간 판서

AI는 사용자가 질문한 내용을 실제 선생님처럼 화면 위에 직접 판서하며 설명한다. 수식, 그래프, 도형 등을 단계적으로 작성하고 음성과 동기화하여 실시간 강의를 제공한다. 사용자는 판서 속도를 조절하거나 일시정지, 다시 보기 기능을 사용할 수 있으며, AI가 작성한 판서를 자신의 노트에 그대로 저장할 수 있다.

---

AI 음성 학습

사용자는 음성으로 질문을 입력할 수 있으며 AI는 음성을 텍스트로 변환하여 질문을 이해한다. 답변은 음성과 텍스트를 함께 제공하며, 강의 녹음을 자동으로 요약하고 핵심 키워드를 추출한다. 또한 반복 청취가 필요한 구간을 추천하고 음성 내용을 자동으로 필기 노트와 연동한다.

---

AI 학습 분석

AI는 공부 시간, 과목별 학습량, 문제 풀이 결과, 오답 패턴, 복습 주기 등을 종합적으로 분석하여 개인 맞춤형 학습 리포트를 생성한다. 부족한 단원을 자동으로 추천하고 학습 난이도를 조절하며, 망각곡선을 기반으로 최적의 복습 시점을 계산하여 알림을 제공한다. 이를 통해 사용자의 학습 효율을 지속적으로 향상시키는 것을 목표로 한다.

---

노트 기능

Notia는 무한 캔버스와 페이지 기반 노트를 모두 지원하며, 다양한 템플릿을 제공하여 과목과 학습 목적에 맞는 필기 환경을 구성할 수 있다. S펜 필압과 손바닥 오작동 방지를 지원하며, 다양한 펜과 형광펜, 도형, 올가미, 텍스트 입력, 이미지 삽입, 표 작성, 수식 입력 등의 기능을 제공한다. 모든 필기는 자동 저장되며 실행 취소와 다시 실행, 버전 복구 기능을 통해 안정적인 필기 환경을 제공한다.

---

학습 관리 기능

공부 시간 측정, 포모도로 타이머, 목표 시간 설정, 과목별 통계, 학습 캘린더, 수행평가 일정, 시험 일정, 숙제 관리 등을 하나의 플랫폼에서 관리할 수 있다. AI는 학습 기록을 분석하여 목표 달성률을 예측하고 효율적인 학습 계획을 추천하며, 복습 일정까지 자동으로 생성하여 체계적인 자기주도학습을 지원한다.

---

최종 목표

Notia는 단순한 필기 애플리케이션이 아니라 AI 개인 과외, 디지털 노트, 문제 풀이, PDF 학습, 공부 기록, 일정 관리, 복습 시스템을 하나로 통합한 올인원 AI 학습 플랫폼을 목표로 한다. 사용자는 하나의 애플리케이션만으로 수업 필기, 문제 풀이, 개념 학습, 시험 준비, 수행평가 준비, 학습 분석, 복습까지 모두 수행할 수 있으며, AI가 학습 전 과정을 지원하는 차세대 스마트 학습 환경을 제공받게 된다.
